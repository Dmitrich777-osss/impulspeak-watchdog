# impulspeak-watchdog

Внешний сторож сайта [impulspeak.com](https://impulspeak.com). Раз в 5 минут GitHub Actions открывает сайт
снаружи; если он не открывается (три попытки подряд), в Telegram приходит сообщение. Когда сайт возвращается,
приходит второе. Пока сайт лежит, напоминание раз в 6 часов.

Зачем отдельно от сервера: основной сторож (`ops/health_monitor.py` в репозитории школы) живёт на самом сервере,
и если упадёт сервер, он замолчит. Этот работает снаружи.

- `check.sh`: проверка и оповещение. Состояние в `status.txt` (up/down, с какого момента, когда последнее оповещение).
- `.github/workflows/watchdog.yml`: расписание.
- Секреты (в настройках репозитория, не в коде): `TG_TOKEN`, `TG_CHAT`.
- Тест: во вкладке Actions запустить workflow вручную с неверным адресом, придёт «🔴», затем запустить с адресом по умолчанию, придёт «🟢».
